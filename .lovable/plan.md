
# 智能商旅助手 - 前端界面设计方案

## 设计风格
- **主题色**: 橙色 (#FF6B2C) + 白色，搭配深灰/炭黑作为文字和背景辅助色
- **设计语言**: 现代科技风，参考Grok的简洁布局 + 豆包的亲和力，融入动漫数字人元素
- **禁止**: 蓝紫渐变、传统AI冷色调
- **特点**: 圆角卡片、微妙的橙色光晕效果、流畅动画过渡

## 页面结构

### 1. 首页/欢迎页
- 居中展示数字人形象（动漫风橙色系角色，带呼吸动效）
- 欢迎语 + 快捷功能入口卡片（行程规划、酒店预订、宴请安排、发票识别）
- 底部对话输入框，两个模式切换按钮：💬 文字模式 / 🎙️ LiveTalking模式

### 2. 文字对话模式（主界面）
- **左侧边栏**（PC端）：历史会话列表 + Agent选择面板
  - Agent列表：显示所有可选Agent（调度、行程规划、出行、酒店、宴请、合规、发票、审批单）
  - 每个Agent有独特的橙色系头像图标
  - 可选择"智能协作"（多Agent自动调度）或点选单一Agent对话
- **主聊天区**：
  - 顶部显示当前对话的Agent标签（如正在与哪些Agent协作）
  - 消息气泡：用户消息右侧，Agent消息左侧带数字人小头像
  - Agent回复中嵌入富内容卡片（航班信息卡、酒店推荐卡、费用合规报告卡、审批单预览卡）
  - 数字人在对话区左上角有一个小窗口形象展示（非全屏，带表情动效）
- **输入区**：文字输入框 + 附件上传（发票图片）+ 发送按钮 + 模式切换
- **移动端**：侧边栏变为底部抽屉，Agent选择变为顶部横向滑动标签

### 3. LiveTalking语音模式
- 全屏展示数字人形象（占据主要视觉区域）
- 底部显示语音波形可视化 + 实时转写文字
- 数字人嘴型动效（占位，后续对接真实动画）
- 悬浮控制栏：麦克风开关、结束对话、切回文字模式
- 右侧可展开的对话记录面板
- Agent协作状态以小标签形式显示在数字人旁边

### 4. 功能卡片组件
- **航班/火车票卡片**：出发到达、时间、价格、合规标签
- **酒店推荐卡片**：图片、星级、价格、距离、合规状态
- **餐厅推荐卡片**：菜系、人均、包间信息
- **审批单卡片**：费用汇总表格、总额、一键导出
- **合规提醒卡片**：超标提示（橙色警告）、替代方案建议

### 5. 数字人形象设计
- 动漫风格，橙色系配色的友好角色形象
- 使用AI生成初版设计，集成到界面中
- 多个表情状态：待机、思考中、回答中、等待输入

## 响应式适配
- **PC端**（≥1024px）：左侧边栏 + 中间对话区的经典布局
- **平板**（768-1024px）：可收起侧边栏
- **手机**（<768px）：全屏对话 + 底部导航 + 顶部Agent切换

## 技术实现
- 所有Agent对话接口使用Mock数据模拟真实多Agent交互流程
- 语音模式先做UI和交互框架，麦克风权限请求 + 波形动画
- Markdown渲染Agent回复内容
- Framer Motion实现页面和模式切换动画
